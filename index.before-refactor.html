DATA NOTES

About this dataset

RoomZero uses the supplied synthetic campus data to demonstrate room discovery and scheduling.

Rooms · 120 records

Room identifiers, building, room type, capacity, facilities, and accessibility details. This powers the room catalog and room filters.

Class schedule · 5,000 records

Recurring weekday and time entries associated with room IDs. Overlapping classes make a room unavailable for the requested time.

Events · 1,800 records

Dated events associated with room IDs and durations. Overlapping events also make a room unavailable.

Room requests · 5,000 records

Historical demand context. Requests are not room assignments, so they are not joined to rooms and do not block availability.

From-scratch ML model

Uses the supplied synthetic event and room data to estimate overflow risk. RoomZero can use this estimate to adjust recommendation rankings; it does not replace hard schedule or room requirements.

Important limitation

These are synthetic educational records, not live campus bookings or measured room occupancy. The prototype does not make reservations.
